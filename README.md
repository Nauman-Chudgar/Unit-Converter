## Metric to Imperial Unit Converter
A simple unit converter for turning common metric measurements into their imperial equivalents. Enter a value, choose a unit, and get the converted result.
Supported conversions
- Length: meters -> feet
- Weight: kilograms -> pounds
- Volume: liters → gallons
## How to use
1. Add a value to input field.
2. Enter convert button.
3. Select its unit.
4. View the equivalent imperial value.
## Conversion formulas
- Feet: meters × 3.28084
- Pounds: kilograms × 2.20462
- US gallons: liters × 0.264172
Results may be rounded for readability. Conversion factors can vary slightly depending on the imperial or customary unit used.

## Notes
This converter is intended for everyday use. For precision-critical work, verify the result and rounding requirements for your application.
